# Student Portfolio using React + Vite

A simple student portfolio website built using **React** and **Vite** as part of the Web Development practical.

## Features

* Reusable React components
* Props for data passing
* Skills rendered dynamically
* Simple and responsive UI

## Practical 3 - API Integration and Data Rendering

* GitHub REST API integration
* useEffect for loading data once on mount
* useState for repository, loading, error, and search state
* Fetch API for retrieving GitHub repositories
* Loading state with a spinner component
* Error handling with a retry button
* Repository search and filtering by name
* Repository star count display
* Dynamic repository rendering

## Technologies Used

* React
* Vite
* JavaScript
* CSS

## Run the Project

```bash
npm install
npm run dev
```

The application will run at:

```text
http://localhost:5173
```

To see your own GitHub repositories, replace the placeholder username in the Projects page with your GitHub username.
